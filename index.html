How it works

A small company of agents.
You are the CEO.

01

Chief of Staff plans

Tell it what you want in one plain sentence. It asks if something is unclear, splits the work into tickets, sends each one to the right project, and writes down every decision.

02

One agent per project

Every project gets its own agent in its own terminal pane, up to six per tab. Each works on its own branch, never on main, and reports back with evidence.

03

Reviewer checks first

Before anything is merged, a Reviewer agent reads the change and writes a verdict. Nothing reaches main without your yes.

FAQ

Questions

What exactly is Helme?

A local app for Windows that opens real terminals for AI coding agents, one per project, and arranges them in tabs and panes. A Chief of Staff agent coordinates them, a Reviewer agent checks their work, and a report area shows what is running and what waits for you.

Do I need to know how to code?

No. Helme was built for an owner who runs several products and does not write code. You give work in plain sentences and answer the decisions that need you.

Which AI does it use?

Project agents run Claude Code by default. The Reviewer is a separate agent with its own instructions, and it can be set to a model from another provider, so the code is checked by a second pair of eyes.

Can an agent spend money or leak my keys?

Not without you. Money, secrets, real data and messages to real people are blocked by default. The agent writes down what it needs and why, and waits for your answer.

Does it run in the cloud?

No. Helme runs on your own PC with Node.js, real terminals and plain files. Your code goes only where your projects already live, such as your own GitHub.

Can I download it?

Not yet. Helme is in private use today. This page only introduces it.
