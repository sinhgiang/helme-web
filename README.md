# helme-web

The introduction page for Helme: one static HTML page, no build step.

- `index.html`: the page
- `styles.css`: styles (black and white, Geist font, thin grid)
- `favicon.svg`: icon

The Helme window on the page is drawn in HTML with fictional projects, so no real data appears.

Run locally: open `index.html` in a browser, or `npx serve .`.
Deploy: Vercel project `helme-web` (static, no framework).
